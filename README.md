# 四非：第一轮投票可玩占位版

这是独立的 Godot 4.4 工程。当前重点是完整流程、原文勾画和说服闭环。旧 RPG Maker 项目未被修改。

## 打开与运行

在 Godot 中导入本目录的 `project.godot`，打开后按 **F5** 运行。主场景为 `scenes/main.tscn`。

本机也可以双击 `运行Demo.command` 直接运行，或双击 `打开Godot工程.command` 进入编辑器。

## 操作

- **WASD / 方向键**：移动。
- **E**：靠近门、人物、开关或案卷后互动。
- **Enter / Space**：继续对白；也可点“继续”。
- **跳过本段**：跳过当前对白段；已公开的关键事实仍写入记录。
- **Esc**：暂停；在档案界面时返回场景。暂停和对白期间不积寒。
- **档案界面**：拖动选中文字，点“勾画并收录”，再在引用卡上点“提交”。句内拖选会在收录时补全整句，跨句选择会被拒绝。引用上限 6 句，每句最多 180 字；可删除再选。

## 已接通的流程

1. 黑屏前情、七人自我介绍，女主在卧室醒来。
2. 出门后选择林梢与沈知、小鹿与老周、阿野与晚晚中的一组。
3. 冷冻室找灯，离炉积寒，冰面加速，收取律师案卷，再回到炉边出口。寒冷到 100 后从入室点重试。
4. 门外林梢补充旧案；会议室查看六份材料。
5. 老周怀疑阿野、主角诈问、林梢确认身份；三轮原文勾画说服。
6. 抵触低于 40 且证据关系完成后，玩家亲自确认投票，进入结尾。

所有分组共用一间冷冻室，分组影响对白。前五份线索默认在开场前取得；律师案卷为本次调查取得的第六份。林梢口述与会议记录不增加线索份数。

## 实现与可编辑位置

| 文件 | 内容 |
| --- | --- |
| `data/dialogue.json` | 前情、自我介绍、分组对白、会议、说服反馈、结尾 |
| `data/clues.json` | 六份线索正文；由已确认的中文稿导入 |
| `data/evidence.json` | 17 个有效选区、对应轮次、关键词和直接反驳标记 |
| `scripts/main.gd` | 流程控制、对白、组队、暂停、投票 |
| `scripts/world.gd` | 房间、碰撞、交互目标、寒冷、火炉、冰面与占位人物 |
| `scripts/player.gd` | 女主移动和旧行走表切帧 |
| `scripts/evidence_panel.gd` | 六份档案、TextEdit 单句勾画、引用槽、提交反馈 |
| `scripts/persuasion.gd` | 三轮证据判定与抵触值结算 |
| `scenes/` | 可分别打开的卧室、走廊、冷冻室、会议室和主场景 |

寒冷速度可在 `cold_room.tscn` 根节点的 Inspector 中调整：普通地面 7.5/秒，冰面 15/秒，炉边恢复 24/秒。卧室和走廊阻挡来自原 RPG Maker 事件格，保存于 `data/map_collisions.json`；冷冻室与会议室的障碍、物件位置集中在 `world.gd`，后续可替换为正式美术场景。

说服采用预设证据关系，不调用在线 AI。每次收录完整的一句话，句中可以同时命中多个有效信息；删去否定词、只抓到“死亡”等孤立关键词不会判为有效。本轮抵触最多下降 20/20/30；同论点只取最高效果。系统衡量的是众人的投票意向，不宣告老周在极点客观有罪。

封面先显示完整镜面和随鼠标轻晃的光圈，点击后裂纹扩散、碎片震动并展开菜单。右侧碎片自上而下为开始游戏、继续游戏、关于作品；支持方向键和 Enter。

进入卧室、走廊、冷冻室和会议阶段会自动写入章节检查点，继续游戏从最近的章节起点恢复；冷冻室重新从入口调查，会议重新整理证据与辩论，不保存逐句对白、精确坐标或中途战斗进度。无存档时继续项置灰。保存使用带版本号的 JSON、临时文件替换和上次备份，位置为 Godot 的 user://checkpoint.json。冷冻室、会议室、其余六人的形象和演出是占位内容；本版尚无配乐、音效与配音。

## 本次视觉与交互修正

- 卧室恢复原工程实际使用的 `new_home` 背景和 `Bed` 前景遮挡。
- 卧室、走廊碰撞按原地图事件格重建；女主恢复 1.8 倍显示，脚部碰撞与立绘尺寸分开。
- 对话接入大小姐、作家、画家、女学生四张立绘，当前发言者居中显示腰部以上，统一腰线接在文本框上沿；旁白和暂无立绘的角色不显示其他人的图片。对话层级高于地图黑暗层，暂停界面再高于对话。
- 单句勾画以句号、问号、叹号和原文换行为边界，自动排版换行不拆句；逗号和分号不拆句。

## 验证

运行下列命令进行自动完整流程检查：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --fixed-fps 60 -- --smoke-test
```

去掉 `--headless` 可同时生成各阶段截图。测试使用实际场景、键盘移动、E 交互、界面按钮和 TextEdit 选区，遍历三种组队；同时检查冰面积寒、暂停、炉边回暖、死亡重试、记录保留、错误及重复证据、身份与付款证据组合、投票确认。报告和截图保存在 `tests/output/`。

测试攻略见 `tests/通关路径.md`；正常游玩无需阅读。

## 四人地图动作

画家使用新图集进行四方向移动；大小姐、作家、女学生在走廊、对应组队的冷冻室位置和会议室使用统一大小的像素角色。站立时播放呼吸帧，并做以脚底为轴的轻微胸肩起伏，碰撞体不缩放。女主播、老周、男学生仍为原占位人物。NPC 保持既定站位，不增加自动跟随或游走逻辑。

四人共用 `scripts/character_visual.gd`；64×64 单帧，显示倍率 1.8，行走 7 帧/秒、待机 2 帧/秒。图集是生成稿经过规范化后的游戏资源，并非原生 64 像素手绘。NPC 已配置四方向行走动画，现有固定站位使用待机。
