四非 · Web 评测版（2026-10-05）

上传方法
1. 解压本压缩包，将全部文件上传到静态网站的同一目录。
2. 网站入口为 index.html。不要只上传 HTML，也不要改名或漏传 .wasm、.pck、.js 文件。
3. 使用 HTTPS 地址访问。无需后端服务；本版为单线程，不要求 COOP/COEP 跨域隔离响应头。
4. 服务器应将 .wasm 作为 application/wasm 提供，并避免将资源请求重定向到 HTML 页面。
5. 推荐电脑浏览器、键盘和鼠标。首次加载需要下载约 78 MiB 的运行资源，请等待加载完成。

本地预览
不能直接双击 index.html。安装 Python 3 后，在本目录执行：
python3 -m http.server 8000
然后在浏览器打开 http://localhost:8000

评测辅助
有效信息提交界面有“评测：跳过本关 F8”按钮，也可以按 F8。
连续提交三次错误信息后会显示需要勾画的具体原句。
如键盘没有响应，请先点击游戏画面使其获得焦点。
浏览器存档属于当前网站和浏览器，清理网站数据或更换网址可能无法继续原存档。

验证范围
Godot 4.4 Web Release 导出成功，并在本地浏览器确认封面加载。
