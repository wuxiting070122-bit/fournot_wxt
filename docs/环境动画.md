# 环境动画第一版

采用 Godot 程序绘制与局部纹理采样动画，无新增生成式美术、无原图修改。

- ambient_effects.gd：10 fps 更新光晕位移、半径、双层火焰轮廓；暖光低透明度，z=-1，高于地图背景但低于角色。
- 走廊：每段地图两盏壁灯；光效跟随循环区段，不新增循环节点。
- 会客厅：九处灯具、两处桌面蜡烛。
- 冷冻室：入口炉火始终开启；深处炉火由 second_lit 控制；三盏上墙灯由 lights_on 控制。暗层照明范围随炉火轻微变化，保留深处无法开灯规则。
- cold_detail_motion.gdshader：只在四处窗帘下缘、两个出风口的霜雾范围内产生约 0.3–1.2 源图像素位移；原背景、墙面和碰撞不移动。危险出风口有同步的流动细线，沿用 wind_active 的危险时段。
- world.active=false 时冻结动画时间；对话、档案、暂停沿用现有停止探索逻辑。

调节：ambient_effects.gd 中 time*10 为分帧频率；pulse 控制明暗幅度，center 控制光晕位移，size 为火舌尺寸，radius 为晕光半径。cold_detail_motion.gdshader 中 gust 控制出风时摆动增幅。

验证：tests/ambient_review.gd（GUI）检查点燃/开灯条件、暂停、角色前后层级，并保存三个场景的渲染截图。tests/fire_preparation_review.gd 检查炉火层级及说服前单次准备流程。
